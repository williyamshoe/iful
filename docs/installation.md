# Installation

## Install via pip (recommended)

```bash
pip install iful
```

## Install from source

Clone the repository and install in editable mode:

```bash
git clone https://github.com/williyamshoe/iful.git
cd iful
pip install -e .
```

Optional extras:

```bash
pip install -e ".[test]"   # pytest, pytest-cov
pip install -e ".[docs]"   # Sphinx + theme, to build these docs
```

Requires Python ≥ 3.10.
